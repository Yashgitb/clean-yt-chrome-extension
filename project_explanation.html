1. Project Overview & Architecture

The YouTube Shorts Hider extension is engineered to block, hide, and redirect algorithmic YouTube Shorts. Because YouTube is a client-side Single Page Application (SPA) driven by Web Components (Polymer), standard static ad-blocking rules fail when users navigate or scroll infinitely. This project implements a coordinated multi-layer solution spanning CSS injection, MutationObserver DOM tracking, and SPA lifecycle interception.

2. How Content is Hidden on the YouTube Page

Layer 1: Scoped Root Class Switching & Relational CSS Selectors

Instead of continuously traversing and removing elements from the DOM with JavaScript (which degrades browser rendering performance), the script toggles a single class on the top-level <html> tag: 

// In content.js
function updateHtmlClass() {
  if (enabled) {
    document.documentElement.classList.add('shorts-hider-active');
  } else {
    document.documentElement.classList.remove('shorts-hider-active');
  }
}

In styles.css, all hiding rules are prefixed with html.shorts-hider-active. When the class is present, the browser's native C++ rendering engine handles all visual occlusion with hardware acceleration:

  • Shorts Shelves & Carousels: Hides horizontal carousels on the homepage and search results using ytd-rich-shelf-renderer[is-shorts] and ytd-reel-shelf-renderer.
  • Individual Shorts in Grids: Uses the modern :has() pseudo-class to match any video tile wrapping a Shorts link: 
    html.shorts-hider-active ytd-rich-item-renderer:has(a[href^="/shorts/"]),
html.shorts-hider-active ytd-video-renderer:has(a[href^="/shorts/"]) {
  display: none !important;
}
  • Sidebar Guide & Channel Tabs: Hides the "Shorts" button from the left navigation drawer and the Shorts tab from YouTube Channel profiles (yt-tab-shape[tab-title="Shorts"]).
  • Watch Page Distraction-Free Player: Removes the recommendation sidebar on video watch pages (ytd-watch-flexy #secondary) and expands the video player container (#primary) to full width (width: 100% !important).

Layer 2: Seamless URL Redirection (Converting Shorts to Full Desktop Player)

If a user directly opens a Shorts URL or clicks an external Shorts link, YouTube loads the TikTok-style vertical player. The extension intercepts this navigation and transforms the URL into standard watch parameters: 

function checkAndRedirect() {
  if (!enabled) return;
  const path = window.location.pathname;
  if (path.startsWith('/shorts/')) {
    const videoId = path.split('/')[2];
    if (videoId) {
      // Replaces history entry to avoid back-button traps
      window.location.replace(`https://www.youtube.com/watch?v=${videoId}`);
    }
  }
}

3. Core JavaScript Concepts Used in the Project

1. MutationObserver API

Monitors DOM subtrees in real-time as YouTube dynamically renders, lazily loads, or removes elements during infinite scrolling.

2. Custom SPA Lifecycle Events

Listens to YouTube's internal yt-navigate-start and yt-navigate-finish custom DOM events for instant route interception.

3. Debouncing & Batching

Uses setTimeout and clearTimeout to batch blocked element statistics and prevent Chrome storage quota exhaustion.

4. CSS Reflow Triggering

Reads void element.offsetWidth to force synchronous style recalculation, restarting CSS keyframe animations reliably.

In-Depth Analysis of JavaScript Techniques

A. Real-Time Mutation Tracking (`MutationObserver`)

Traditional DOM events like DOMContentLoaded only fire once on initial load. Since YouTube is an SPA, new videos load continuously via AJAX. The extension attaches a MutationObserver to the document root: 

const observer = new MutationObserver(() => {
  if (window.location.href !== currentUrl) {
    currentUrl = window.location.href;
    checkAndRedirect();
  }
  if (enabled) {
    countAndHideElements();
  }
});
observer.observe(document.documentElement, { childList: true, subtree: true });

childList: true captures direct DOM insertion of video cards, while subtree: true ensures deep nested changes inside Polymer shadow/light DOM trees are observed.

B. DOM Attribute Tagging & Deduplication

To calculate how many Shorts have been hidden without overcounting elements across multiple observer passes, the script tags counted nodes with a custom HTML attribute: 

const elements = document.querySelectorAll(`${selector}:not([data-shorts-counted])`);
elements.forEach(el => {
  el.setAttribute('data-shorts-counted', 'true');
  foundNew++;
});

C. Debouncing Write Operations to Chrome Storage

Writing to chrome.storage.local on every discovered element would hit the browser's MAX_WRITE_OPERATIONS_PER_MINUTE quota. A 300ms debounce buffer aggregates counts: 

if (foundNew > 0) {
  pendingCount += foundNew;
  if (saveTimeout) clearTimeout(saveTimeout);
  saveTimeout = setTimeout(() => {
    chrome.storage.local.get({ blockedCount: 0 }, (data) => {
      chrome.storage.local.set({ blockedCount: data.blockedCount + pendingCount }, () => {
        pendingCount = 0;
      });
    });
  }, 300);
}

Video ID Extraction & Uniform Resource Anatomy

Both YouTube Shorts and standard desktop videos reference the identical 11-character base-64 alphanumeric video identifier in YouTube's media backend.

URL Transformation Mechanics
Shorts Route: https://www.youtube.com/shorts/dQw4w9WgXcQ
Watch Route: https://www.youtube.com/watch?v=dQw4w9WgXcQ
By redirecting the path parameter into the query parameter (?v=ID), YouTube loads the standard video player with full desktop controls (scrubber bar, playback speed options, theater mode, volume sliders, and full comment threads).

Extension Lifecycle & Context Isolation

The extension is configured with "run_at": "document_start" in manifest.json. This guarantees:

  • Zero Flash of Unstyled Content (FOUC): The CSS and initial class are injected before HTML body parsing completes, preventing Shorts thumbnails from flashing briefly before vanishing.
  • Isolated World Security: content.js operates in a private sandbox. It can manipulate DOM elements directly without YouTube's frontend scripts accessing extension variables or functions.
  • Event-Driven Storage Synchronization: When the user toggles the extension in popup.html, a chrome.storage.onChanged event broadcasts to all YouTube tabs, instantly enabling or disabling rules without a page reload.
